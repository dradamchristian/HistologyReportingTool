Cancer resection accumulator example
You can dictate nodes and pT stage in chunks (for example, slide by slide). The generator will total nodes and keep the worst pT stage.
  • "1/3 nodes, 4 nodes, 5/7 nodes, pT2 pT3"
  • Expected behaviour: nodes positive/examined = 6/14 and pT = pT3.

    Quick shorthand guide (Lower GI biopsies)
    
    
    Use this when reporting multi-part colon/small bowel biopsies. Start the dictation with LGI: to trigger shorthand mode.
    
    
    
      
    Basic format
    
      
      
        
    • LGI: A - <site> <codes>; B - <site> <codes>
      • 
        
    • Example: LGI: A - ti n; B - rectum uc ad cryp pat; C - sigmoid cmv
      • 
        
    • Range shortcut: LGI: A-D n (expands to A, B, C, D all normal).
      • 
      
    
    
    

    
    
      
    
        
    Sites
    
        
    ti = terminal ileum, cae = caecum, asc = ascending, tra = transverse, des = descending, sig = sigmoid, rec = rectum.
    
      
    
      
    
        
    Inflammatory / other findings
    
        
    n = normal, ad = architectural distortion, bp = basal plasmacytosis, cryp = cryptitis, absc = crypt abscesses, gran = granulomas (Crohn-favouring when non-cryptolytic), cgran = cryptolytic/ruptured-crypt granulomas, ulc = ulceration, pat = patchy, dif = diffuse, uc = ulcerative colitis context, isch = ischaemia, wither = withered crypts, cmv = CMV concern, drug = drug-type injury, eos = eosinophilia, crc = well to moderately differentiated adenocarcinoma (MMR to follow), crc p = poorly differentiated adenocarcinoma (MMR to follow).
    
      
    
      
    
        
    Polyp / dysplasia codes
    
        
    TA = tubular adenoma, TVA = tubulovillous adenoma, V = villous adenoma, HP = hyperplastic polyp, SSL = sessile serrated lesion, TSA = traditional serrated adenoma, HGD = high-grade dysplasia, inv = invasive malignancy, e = excised, ne = not fully excised, plus size e.g. 12mm.
